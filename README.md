# Python Shopping Cart Application

## Project Overview

This project is a Python shopping cart application developed on October 10, 2026. It demonstrates object-oriented programming principles through the use of classes, constructors, methods, and lists.

The application allows users to manage items in a shopping cart and calculate the total cost of their purchases.

## Features

- Create a shopping cart with customer information
- Add items to the shopping cart
- Remove items from the shopping cart
- Modify item quantities
- Display item descriptions
- Calculate and display the total shopping cart cost
- Navigate the application using a menu-driven interface

## Programming Concepts

- Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors and Instance Attributes
- Methods
- Lists and Iteration
- Conditional Statements
- User Input and Output

## Technologies Used

- Python 3

## How to Run

1. Download or clone this repository.
2. Open the program in a Python-compatible development environment.
3. Run the following command:

   `python shopping_cart.py`

4. Follow the menu prompts to manage your shopping cart.
